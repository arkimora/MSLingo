# MSLingo — Монгол дохионы хэл

**Интернэтгүй ажилладаг Монгол дохионы хэл (MSL) сургалтын апп** — https://mnsl.mn сайтаас авсан хэлний агуулгатай.

## Юу вэ

Дуолинго шиг сургалтын апп. **Бүртгэл шаардлагагүй. Облак үгүй. Зохисгүй агуулга байхгүй.** Бүх дохио, утга, жишээ, грамматик цэг нь mnsl.mn сайтаас гаралтай.

## Хурдан эхлэх

```bash
npm install
npm run dev          # хөгжүүлэлтийн сервер: http://localhost:5173
```

Апп хоосон агуулгатай эхэлдэг. mnsl.mn-оос бодит MSL агуулга авч тохируулахын тулд:

```bash
npm run sync:mnsl          # mnsl.mn-оос бүх дохио + сэдвүүдийг татна
npm run extract:info       # грамматик/мэдээлэл хуудсуудыг татна
npm run validate:msl       # бүрэн бүтэн байдлыг шалгана
npm run build              # prod хувилбар
```

## Технологи

- **Vite 6 + React 19 + TypeScript** — хурдан хөгжүүлэлт
- **vite-plugin-pwa** — суулгаж болдог, интернэтгүй ажиллана. Workbox-оор mnsl.mn медиаг шаардлагаар кэшлэдэг.
- **Dexie.js** — локал IndexedDB: явцын түүх, гүнзгийрэлт, дахин үзэх, дуртай тэмдэглэл, гүйцэтгэл
- **ts-fsrs** — FSRS зайтууд дахин давтамжийн алгоритм
- **FlexSearch** — 1,398 дохион дээр локал бүтэн текст хайлт
- **Zod** — агуулгын схем баталгаа (багдаш болон runtime)
- **Tailwind CSS v4** — CSS-ээс дизайн токенүүд `@theme {}`-р

## Агуулгын багц

```
content/msl/
  signs.json         1,398 дохио
  topics.json        85 сэдэв
  grammar.json       8 грамматик/мэдээлэл хуудас
  fingerspelling.json  Монгол цагаан толгойн гарын яриа
  numbers.json       Тоо
  meta.json          Импортлогдсон огноо, эх сурвалж, статистик

scripts/
  sync-mnsl.ts       mnsl.mn REST API-с дохио + сэдвүүдийг импортлох
  extract-info.ts     mnsl.mn-оос грамматик/мэдээлэл хуудсууд
  validate-msl.ts    Агуулгын багцыг Zod-р шалгах

tests/
  lib/             Unit тест (Vitest) — srs, progress, schema
  e2e/             Playwright E2E — нүүр, толь, тохиргоо, профайл
```

## Хэлний нарийвчлал

Энэ апп нь mnsl.mn-ийн зүсэм юм. Гол дүрэм:

- **Бид дохио, утга, жишээ, грамматик зүйл зохиохгүй.** Хэрэв эх сурвалжинд юу ч алга бол үүнд харгалзах UI хэсгийг харуулдаггүй.
- **Дохионы хувилбарууд нь анхны өгөгдөл юм.** Нэг утгын хувьд олон зөв дохио хүлээн авдаг.
- **Дохионы таван хэсэг** (гарын хэлбэр, байршил, хөдөлгөөн, алах чиглэл, биеийн хэлбэр) хадгалдагддаг.
- **Уламжлалт Монгол бичиг** нь кириллтэй хамт хадгалдагддаг.
- **Эх сурвалжийн танилцуулга** нь дохионы дэлгэрэнгүй хуудсанд болон аппын footer-д харагдана.

## Тестлэл

```bash
npm run test               # Vitest unit тест
npm run test:e2e           # Playwright E2E (dev сервер шаардлагатай)
npx tsc --noEmit           # Typecheck
```

CI нь бүх push дээр гуруулаа ажиллуулдаг — `.github/workflows/ci.yml` харна уу.

## Android APK (TWA)

PWA-г Trusted Web Activity-ээр Android апп болгон гаргана. `twa/SIGNING.md` файлд бүрэн заавар (keytool генератор, локал гарын үсэг, CI гарын үсэг, Play Store) байна.

```bash
# Локал debug хувилбар (JDK 17 + Android SDK шаардлагатай)
cd twa && ./gradlew assembleDebug
```
